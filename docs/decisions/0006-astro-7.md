# 0006. Astro 7 instead of Astro 6

- Status: proposed
- Date: 2026-11-11

## Context

The design names Astro 6. When the web scaffold was created, the current stable major on
npm was Astro 7 (7.0.0 released on 22 June 2026, 7.4.10 at the time of writing). The site
has no code yet, so there is nothing to migrate.

## Decision

Proposed: start on Astro 7. The scaffold uses static output only, with no adapter.

## Alternatives

- Astro 6, as written in the design. It would start a new project one major behind and
  schedule a migration before launch.

## Consequences

- Claims in the design that were checked against Astro 6 (the Cloudflare adapter, on-demand
  rendering of the archive) must be checked again on Astro 7 when milestone M8 starts.
- `@astrojs/check` supports TypeScript 5 and 6, so the site stays on TypeScript 6 for now.
